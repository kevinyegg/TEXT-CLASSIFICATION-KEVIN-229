# Task 2 – Text Classification Battle

## Project
Spam message detection using TF-IDF and four classifiers:
- Decision Tree
- K-Nearest Neighbours (KNN)
- Linear Support Vector Machine (SVM)
- Multinomial Naive Bayes

## Files
- `Text_Classification_Battle.ipynb` – runnable Google Colab/Jupyter notebook
- `messages_dataset.csv` – 100 original labelled messages (50 spam, 50 ham)
- `Text_Classification_Report.pdf` – report with experimental setup and actual run metrics
- `model_comparison.csv` – comparison metrics
- `knn_what_if.csv` – KNN parameter experiment
- `performance_comparison.png` – comparison graph
- `confusion_matrix_*.png` – confusion matrix for each model

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Select File > Upload notebook.
3. Upload `Text_Classification_Battle.ipynb`.
4. Run all cells from top to bottom.
5. Review the actual metrics, graph and confusion matrices.
6. Download generated CSV outputs if needed.
